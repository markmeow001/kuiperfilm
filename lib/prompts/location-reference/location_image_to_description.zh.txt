# 图片反推场景描述提示词

请分析这张场景/环境图片，生成一段详细的场景视觉描述（用于 AI 图片生成做镜头背景）。

## 输出要求

生成一段完整的场景视觉描述，按照下面的要素覆盖，全部融成一段连贯的文字：

1. 空间类型（如：山间洞府、现代客厅、办公大楼大厅、古风庭院、地下停车场）
2. 时间与光线（如：清晨柔和侧光、正午顶光、黄昏暖色逆光、夜晚冷调环境光、阴天散射光）
3. 主要建筑/陈设特征（如：白玉石台、原木长桌、皮质沙发、青砖墙面、玻璃幕墙、莲花池）
4. 材质与色调（如：石壁青灰、地面打磨大理石、木质温暖棕黄、整体冷色调偏蓝）
5. 装饰细节（如：墙上挂卷轴、桌上摆茶具、地面散落落叶、天花板悬挂吊灯、远处雕花屏风）
6. 空间纵深与构图（如：广角对称构图、前景藤蔓中景石台远景洞壁、低角度仰拍突出穹顶高度）
7. 整体氛围关键词（如：幽静神秘、商务冷峻、温馨生活感、压抑阴森、奢华大气）

## 缺失内容补齐规则

如果参考图视角受限（如只露天花板一角、只拍局部桌面），根据已有线索合理推断并补全周边环境：
- **只有局部物件**：推断这是哪种空间的局部，补全外推的整体格局描述
- **缺乏光照线索**：根据空间类型推断常见光照（古风洞府偏穹顶天光，现代客厅偏侧窗光）
- **缺乏颜色信息**：根据材质推断色调（青砖偏冷灰、原木偏暖棕）

## 禁止描写

- 角色人物（场景描述只描述空间，不写人物）
- 表情、动作、姿势
- 镜头机位术语（wide shot、close-up 等保留给分镜阶段）
- 摄影机品牌或参数

## 输出格式

一段连贯的描述文字，约200-300字，直接可用于图片生成提示词。
只返回描述文字，不要有任何标题、序号或其他格式。
