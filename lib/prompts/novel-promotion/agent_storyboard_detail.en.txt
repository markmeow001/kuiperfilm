Composition and frame layering (Cinematic richness — added 2026-05-21):

video_prompt must do more than describe "subject does X" — every shot
needs explicit GEOMETRY and LAYERS. Equipment terms remain banned (see
red line #4 below) since those are handled by the project's styleAnchor;
this section is about what the human eye sees in frame, not what camera
captured it.

Composition cues (include at least ONE per video_prompt, after the subject):
  - Centered framing — for ritual, confrontation, key freeze moments
    "@Character A stands centered, ..."
  - Rule of thirds (1/3 left or 1/3 right) — natural daily, negative space
    "@Character A stands in the right-third of the frame, ..."
  - Symmetrical composition — solemnity, fate, abstract
    "Symmetrical composition, @Character A centered, stone pillars on
     each side, ..."
  - Foreground + midground + background (3 layers) — for medium+ wide shots
    "Foreground a puddle, midground @Character A running, background a
     lightning-struck cliff"
  - Negative space — lyrical, loneliness
    "@Character A occupies the right third, large sky negative space left"
  - Low-angle + subject filling frame — intimidation, epic
    "Low-angle upward, @Character A towers, fills the frame top-to-bottom"
  - High-angle + subject diminutive — smallness, overview
    "High-angle 45°, @Character A in the lower quarter like a small dot"
  - Over-the-shoulder + background blur — dialogue, confrontation
    "Over-the-shoulder of @Character A, @Character B's back fills the
     left third foreground"
  - Frame-within-frame — voyeurism, entrapment
    "@Character A inside the window frame, the metal sash frames the
     outer edges of the shot"

Frame-layer cues (any shot wider than medium close-up MUST name 2 layers):
  Foreground: object, prop, character back, rain, smoke
  Midground:  subject's action
  Background: distant architecture, nature, crowd action

Five-element red lines (CRITICAL — applies to both description AND video_prompt):

Core balance (recalibrated 2026-05-29): KEEP ACTIONS LEAN (1 main beat) BUT
WRITE THE PICTURE RICH. The only "overstuffing" to avoid is: (1) stacked
sequential actions (rule 2), (2) repeating appearance already in the refs
(rule 1). Everything else — spatial anchors, ambient sound, micro-action
layering, composition layers — must be written FULLY and concretely, not
omitted. A thin one-sentence prose line = the model improvises = sparse,
content-dropping output; dense description focused on ONE main beat = the
model has clear direction = complete, faithful output.

  1. NO appearance details already in @image-N references (body, skin, hair,
     clothing). Write only current action / emotion / expression.
     Wrong: "@WangXuan's chest heaves, neck veins bulge, skin flushes, pores
            and sweat visible, long hair blown by wind" (entirely appearance)
     Right: "@WangXuan's aura bursts forth, chest heaves, vortex forms"
            (action + result)
  2. One MAIN action per panel (+ optional wind-up / settle micro-motion);
     composition visual points are unlimited. Key distinction (this is the
     root cause of "the description doesn't render, the back half is skipped"):
       - "Visual points" = elements coexisting in the same instant (fore/mid/
         background layers, expression, gesture, light) → as many as you like,
         they share the frame and cost no extra time.
       - "Action beats" = events that happen in sequence (cat leaps → lands →
         morphs → walks → touches) → one main action per panel. A clip is only
         a few seconds; pack 2+ sequential actions and the model renders only
         the first and cuts away, dropping the rest (a measured bug).
     One period / one "→" / one "then" = one action beat. More than one main
     beat → split to the next panel (see split rule c).
     Right: "@woman slowly turns to the window, brow faintly furrowing"
            (1 main action = turn + micro expression, rich composition)
     Wrong: "@woman stands, walks to the door, opens it, turns and smiles"
            (4 sequential actions in one panel → only "stands" renders)
  3. NO negative directives ("no X", "no subtitles", "no on-screen text",
     "strictly without X") — handled by the worker's dedicated
     negative_prompt field. Mentioning them in the positive prompt
     probabilistically triggers the very artifact you're trying to avoid.
  4. NO camera / equipment terms ("Arri Alexa", "IMAX", "film grain", "8K",
     "35mm lens", "cinematic lighting") — handled by project visualStyleId
     / styleAnchor. video_prompt describes what's in frame, not the camera.
  5. NO vague collective nouns ("crowd", "everyone", "people", "all of
     them", "the group") — name specific characters or give a count.
  6. REQUIRED: every panel includes one "Ambient sound: …" line with a
     concrete PHYSICAL source (collar rustle / cold wind through metal
     grating / countdown ticking / footsteps / rain…). This is part of the
     output quality and must NOT be omitted (the old "optional, omit it" rule
     is retired).
     WARNING: for SILENT (no-dialogue) shots, avoid words like "bass drone",
     "low bass", "hum", "droning" that Seedance tends to mistake for a VOICE
     timbre and synthesize as a human-like hum (unexpected vocal artifact);
     rewrite as pure physical sources (low wind / distant machinery rumble /
     spatial reverb). No such limit when the shot has dialogue.
     Only EXTREME facial detail (pores / sweat reflection / micro-redness) stays
     reserved for emotional-peak close-ups.
  7. Dialogue lines ≤ 30 words each — long lines destabilize TTS.

⚠️ Transformation / morph / shapeshift rule (added 2026-05-28):

Generative models (Seedance / Kling R2V) CANNOT gradually morph one subject
into a different reference image within a single clip — e.g. "the black cat
lands and morphs into @Vera". Reference images are identity anchors (image N
= character "X" looks like this); the model only renders one state (either a
cat throughout, or Vera outright), the "morph" transition is always lost, and
the following actions often get dropped with it.

When the source has "X morphs / transforms / takes the form of / reveals true
form as Y": you MUST split into two panels and express the change via the cut.
NEVER ask a single R2V clip to fully replace the subject.

  Wrong (single-clip morph + multi-action, measured to render only beat 1):
    "a black cat leaps from the pillar shadow, lands and morphs into @Vera,
     she walks to @William and strokes his shoulder"
  Right (two panels, each one clear state):
    Panel 1: "a black cat leaps from the pillar shadow and lands lightly"
             (cat only, no human form)
    Panel 2: "@Vera now stands in place, steps toward @William" (human from
             the first frame, 1 main action)

Same for appear / vanish / summon / teleport — any "subject replaced out of
nowhere" transition: split into "before" + "after" panels, leave the change
to the cut.

Dramatic camera vocabulary (prefer these terms in video_prompt when context
matches — do NOT invent abstract phrasing like "mysteriously orbit" or
"cool pull-back"):

  | Context                      | Term                |
  |------------------------------|---------------------|
  | Slow reveal / push-in        | dolly in            |
  | Combat / ritual              | orbit / 360 spin    |
  | Inner shock / cognition flip | dolly zoom          |
  | Long take / immersive        | oner                |
  | Key moment freeze            | time freeze orbit   |
  | First-person / fall / impact | POV                 |
  | Grandeur / wide              | 45° high angle      |
  | Following motion             | tracking / handheld |
  | Tension                      | crash zoom          |

When to use:
- "dolly zoom" for cognition flips, sudden realizations, frozen horror
- "orbit / 360 spin" for sword practice / duels / rituals / breakthroughs
- "oner" for long dialogues / single-scene multi-action choreography
- "time freeze orbit" for sword arcs / bullets / raindrops / key instants
- "POV" for falls, getting hit, waking up, high-speed travel
- "45° high angle" for grand vistas / armies / cities
