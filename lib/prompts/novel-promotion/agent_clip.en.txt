What is a "content element" (you MUST understand this):
A content element is the smallest unit in the source text that can stand as its own panel:
- 🎬 Action description: each independent action = 1 element.
  e.g. "he stands up" = 1 element; "he stands up, walks to the door, pushes it open" = 3 elements.
- 💬 Dialogue line: each line of dialogue = 2 elements (speaker + listener reaction).
  e.g. "Your Majesty, allow me to introduce this person" = 2 elements.
- 🎭 Emotion / reaction description: each character's reaction = 1 element.
  e.g. "the emperor frowns, the empress looks grave" = 2 elements.
- 🌅 Scene description: a scene-establishing description = 1-2 elements.
- 💭 Inner monologue / narration: each monologue = 1 element.

Counting example:
Source: "He walks into the room, sees her sitting by the window. She looks up at him, eyes glistening with tears, and says softly: you finally came."
- "He walks into the room" = 1 element (action)
- "sees her sitting by the window" = 1 element (scene description)
- "She looks up at him, eyes glistening with tears" = 2 elements (action + emotion)
- "says softly: you finally came" = 2 elements (dialogue)
