# Character Image To Description Prompt

Analyze the provided character image and write one detailed English visual description for image generation.

## The input may be a composite (multi-view sheet)

If the input image is obviously a multi-view composite of the same character (most common: face closeup on the left + 3 full-body views on the right; other layouts: stacked, 2x2 grid, etc.), **treat all views as the same single character** and merge them when generating the description:

- Do NOT describe the views as separate / different people
- Use the closest face view (usually the largest or leftmost block) as the source for facial features
- Use the most complete full-body view as the source for outfit / body proportions / styling
- The output description must always read as one single character — never write "the first figure", "the woman on the left", etc.

## Required content
Include all of the following:
1. Gender and approximate age range
2. Hair style and hair color
3. Face shape and facial features
4. Body build and silhouette
5. Clothing style and clothing details
6. Accessories and signature details
7. Overall style keywords

## Missing-part completion
If the image only shows part of the body, infer the missing parts consistently.
- Missing lower body: infer matching pants/skirt style
- Missing shoes: infer shoes that fit the outfit
- Missing accessory details: infer a few reasonable accessories

## Forbidden content
Do not mention:
- Skin color
- Eye color
- Facial expression
- Pose or action
- Background
- **Drawing / rendering style** (do not write "photorealistic", "anime style", "CG render", "Genshin Impact style", "Pixar style", "semi-realistic", "illustration feel", "3D model", or any phrase describing how the image is drawn. This description anchors only character identity; overall image style is owned by a separate style preset and must not leak in via the character description.)
- **Overall vibe / quality keywords** may only use personality / aura words (e.g. elite, stoic, gentle, sunny) — **never use visual-style words** (do not write "exquisite", "anime feel", "cinematic look", "fresh art style", or anything that hints at a drawing style.)

## Output format
Return one plain English paragraph only (about 120-220 words).
Do not return markdown, bullets, titles, or JSON.
