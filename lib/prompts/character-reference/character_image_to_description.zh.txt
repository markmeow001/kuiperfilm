# 图片反推角色描述提示词

请分析这张角色图片，生成一段详细的角色外貌描述（用于 AI 图片生成）。

## 输入图片可能是「拼贴/多视角图」

如果输入图片明显是把同一个角色的多个视角拼在一张画布上（最常见版面：左侧大头特写 + 右侧 3 个全身视角；其他可能：上下分块、2x2 grid 等），**请把所有视角都视为同一角色**，合并理解后再生成描述：

- **不要**把不同视角描述成不同人物
- 面容五官以「特写」/最清晰的那一格为准（通常在左侧或最大的那块）
- 服装款式 / 整体造型 / 体态以最完整的全身视角为准
- 描述本身始终以「单个角色」的口吻撰写，不要出现「图中第一个人」「左侧的女子」等多人指称

## 输出要求

生成一段完整的角色视觉描述，包含以下要素：

1. 性别和年龄段（如：约二十五岁的男性）
2. 发型发色（如：黑色短发、微卷的棕色长发）
3. 脸型五官特征（如：剑眉星目、高鼻梁、薄唇）
4. 体态身材（如：身形修长、体格健壮）
5. 服装风格（如：深蓝色西装、白色衬衫、皮质腰带）
6. 配饰特征（如：左手戴银色手表、胸前别金色胸针）
7. 整体气质关键词（如：精英气质、禁欲系、高冷、温柔暖男）

## 缺失内容补齐规则

如果参考图只展示了部分身体（如上半身、头像），请根据已有信息合理推断并补全：
- **缺少下半身**：根据上衣风格推断裤装/裙装类型（如西装上衣配深蓝色西裤、休闲上衣配牛仔裤）
- **缺少鞋子**：根据整体穿搭风格推断鞋款（如正装配皮鞋、休闲装配运动鞋或帆布鞋）
- **缺少配饰细节**：根据角色气质合理添加配饰（如商务风配手表、休闲风配手环）

## 禁止描写

- 皮肤颜色
- 眼睛颜色
- 表情
- 动作
- 背景
- 姿势
- **绘画风格 / 渲染风格 / 画风**（例如：不要写「写实风」「动漫风」「CG 渲染」「原神画风」「二次元」「插画感」「3D 模型」「皮克斯风」「半写实」等任何描述「图怎么画出来」的词。本描述只锁角色身份特征，画面整体风格由独立的 style preset 决定，不该由角色描述带入。）
- **整体气质** 只能用人物性格 / 气场词（如：精英、禁欲、温柔、阳光），**不可用画面风格词**（不要写「精致细腻」「日漫感」「电影感」「画风清新」等暗示绘画风格的字眼）

## 输出格式

一段连贯的描述文字，约200-300字，直接可用于图片生成提示词。
只返回描述文字，不要有任何标题、序号或其他格式。
