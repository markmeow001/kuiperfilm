# 图片反推道具描述提示词

请分析这张道具/物件图片，生成一段详细的道具视觉描述（用于 AI 图片生成时把这件道具放进镜头）。

## 输出要求

生成一段连贯的描述文字，覆盖以下要素：

1. 道具类别（如：长剑、信封、戒指、茶杯、智能手机、卷轴、青铜鼎）
2. 形状与尺寸（如：约一米长的窄刃长剑、A4 大小的牛皮纸信封、戒指内圈直径约 18mm）
3. 材质与做工（如：精钢剑身配青铜剑格、手工蜡封信封、18K 金嵌祖母绿、手工刻花青瓷）
4. 颜色与表面纹理（如：剑身冷光银白、信封暗黄微泛旧斑、瓷面青绿釉色裂纹）
5. 装饰细节与磨损（如：剑柄缠红色丝绦、信封封蜡印家族纹章、戒指内圈刻字、瓷杯沿一道细微缺口）
6. 整体气质关键词（如：古朴沧桑、奢华贵重、日常使用感、神秘符文、未来感）

## 缺失内容补齐规则

- **只露出局部**：根据可见部位推断整体形态（只看到剑柄→补全剑身、剑鞘）
- **缺失尺寸参照**：参考常见尺寸（手机约 15cm、戒指约 2cm、长剑约 1m）
- **缺失颜色细节**：根据材质合理推断（青铜偏黄绿、纯铁偏深灰）

## 禁止描写

- 持有者/人物
- 使用场景（道具描述只写道具本体，不写「放在桌上」「角色握着」）
- 摄影机机位、光线方向、构图（保留给分镜阶段）
- **绘画风格 / 渲染风格 / 画风**（不要写「写实风」「动漫感」「CG 渲染」「3D 模型」「插画感」「皮克斯风」等任何描述「图怎么画出来」的词。道具描述只锁物件的形状、材质、纹理、磨损，画面整体风格由独立的 style preset 决定。）
- **整体气质关键词** 只能用物件本身的属性词（如：古朴、奢华、未来感、神秘符文），**不可用画面风格词**（不要写「精致细腻」「电影感」「画面华丽」等暗示绘画风格的字眼）

## 输出格式

一段连贯的描述文字，约150-250字，直接可用于图片生成提示词。
只返回描述文字，不要有任何标题、序号或其他格式。
