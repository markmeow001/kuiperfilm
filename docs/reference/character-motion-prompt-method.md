# 人物動作描述提示詞方法論（讓 AI 影片人物動作更自然）

> 來源：刺蝟星球 super-i《提示詞創作第五十四節》（作者：西瓜）
> 用途：作為 KuiperAI 影片 prompt 生成（LLM video_prompt / description）的人物動作描寫指南
> 整理日期：2026-06-02

## 核心問題與原則

AI 影片 vs AI 圖片最大差別 = **時間變化**。圖片定格一個瞬間，影片要讓人物「從一個狀態過渡到另一個狀態」。

動作僵硬（滑行、上半身不動、腿不協調、像現代人走路）的根因 = **只寫「人物做什麼」，沒寫「人物怎麼一步步完成」**。

**總綱：不要只寫人物在走，要寫清楚人物怎麼走。**

## 八個遞進層次

### 1. 步態（怎麼走）
先判斷角色氣質再決定走法，而不是急著讓人物動。
- 古風宮廷女子 → 緩慢、端莊、平穩，衣袖隨腳步輕擺
- 夜街紅衣女 → 放輕、克制、謹慎，像夜色中小心前行
- 寫「緩緩地走 / 輕輕地走 / 帶謹慎感地走」，而非「往前走」

### 2. 身體聯動
真人動作時不會只有一個部位動。抬頭 → 視線跟著變、肩膀帶動、手臂和手中物件微動。
**口訣：不要只寫一個動作，順手補上其他部位的細微配合。**
氣質安靜的角色，聯動也要輕，重點放頭部 / 肩膀 / 手臂 / 上身的微小變化。

### 3. 情緒與狀態
同一個「低頭看東西」：平靜看 / 猶豫看 / 隱忍看，眼神、手上力度、呼吸感、抬眼方式都不同。
**公式：動作前面加原因，動作裡面加情緒，動作後面加狀態。**

### 4. 動作鏈（複雜動作的核心）
把一個動作拆成完整過程：

```
起始狀態 + 觸發原因 + 調整動作 + 身體發力 + 主動作 + 情緒變化 + 結束定格 + 鏡頭配合
```

口語版：人物原本在做什麼 → 因為什麼開始動 → 動之前身體有什麼準備 → 動作怎麼發生 → 動作之後停在什麼狀態 → 鏡頭怎麼記錄。

範例（少年揮長桿）：握桿對峙 → 手指收緊手腕下壓肩膀繃住身體重心降低（蓄力）→ 腰部肩膀帶動雙臂發力 → 長桿右向左橫掃 → 劃出弧線掠過鏡頭 → 身體側轉長桿停左側眼神鎖定（結束）→ 鏡頭後退跟隨橫掃方向。

### 5. 多人畫面分角色寫
```
主角色：位置 + 主動作 + 情緒狀態
副角色：位置 + 回應動作 + 情緒狀態
互動關係：誰靠近 / 誰後退 / 誰阻止 / 誰回應
結束狀態：兩人最後停在什麼關係裡
```
範例：男子靠近 → 女子後撤 → 男子按住手腕 → 女子抬頭回應 → 兩人對視停住。
**口訣：不要只寫兩個人在一起，要寫清楚兩個人怎麼互動。**

## 兩個可直接套用的萬用公式

**通用模板：**
```
人物身份 + 場景 + 起始狀態 + 動作過程 + 身體聯動 + 情緒狀態 + 結束狀態 + 鏡頭運動 + 影片氛圍
```

**最終公式（拆解版）：**
```
人物身份 + 場景氛圍 + 情緒狀態 + 主動作 + 輔助動態 + 身體聯動 + 結束狀態 + 簡單鏡頭
```
- 人物身份：她是誰？古風女子 / 少年俠客 / 紅衣男子
- 場景氛圍：她在哪裡？夜晚古街 / 昏暗祠堂 / 室內燈籠下
- 情緒狀態：緊張 / 壓抑 / 從容 / 決絕 / 警覺 / 克制
- 主動作：向前走 / 轉身 / 抬頭 / 靠近 / 後退 / 揮桿 / 抬手阻止
- 輔助動態：整理衣袖 / 手指緊握 / 輕輕側身 / 髮絲晃動
- 身體聯動：動作發生時肩膀、上身、手臂、頭部自然配合
- 結束狀態：抬眼定格 / 對視停住 / 站定回望 / 動作完成後保持防備
- 簡單鏡頭：緩慢推進 / 側面跟隨 / 中近景 / 保持人物居中

## 六條總結（檢查清單）
1. 先寫清楚人物怎麼動（緩慢 / 謹慎 / 端莊 / 沉穩），不要只寫「走路」
2. 加一點輔助動態（衣袖、髮絲、眼神、手指），讓影片不單調
3. 動作要有身體聯動（抬頭/轉身/抬手時肩膀上身手臂跟著配合）
4. 加入情緒和狀態（同動作不同情緒 → 完全不同感覺）
5. 把動作寫成簡單動作鏈：起始狀態 → 主動作 → 輔助動作 → 結束狀態（不要只寫一個小動作，也不要堆太多）
6. 多人畫面分角色寫（誰先動、誰回應、最後停在什麼關係）

**一句話：AI 影片提示詞要有主動作、有狀態、有結束畫面。人物才會動得自然，也更有故事感。**

## 反面教材（要避免的寫法）
- 「一個女孩往前走」→ 滑行 / 動作僵硬
- 「少年揮動長桿」→ 太突然、有些傻
- 「一男一女在房間裡對視」→ 只有眨眼、畫面無變化
- 「女子低頭看著手中的布帛」→ 畫面很平，沒有情緒
