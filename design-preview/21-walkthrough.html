📍 GUIDED WALKTHROUGH

怎么在创作流程中进到「剧集设定」

用 4 个关键位置走一遍 — 从项目仪表 → 文本分析确认 → 叙事编辑。每个位置都有金色 callout 标出来，点开连结直接到该页。

1

從 02 Home — 左側 sidebar「劇集設定」

什麼時候用：剛登入想直接管理某個项目的角色 / 場景 / 道具
開啟 02 Home →
創作
▣ 项目12
▸ 範本
點這 → ◇ 劇集設定7
♪ 音色

怎麼點

  1. 登入後到 02 Home
  2. 看左邊 sidebar「創作」分組
  3. 點第三個「◇ 劇集設定」（金色 badge 顯示 7 個元素）

→ 跳到 15-character-edit，預設打開角色 tab

2

從 07 文本分析確認 — Element 卡片直接點

什麼時候用：劇本剛分析完，看到抽出的角色想趕快補圖
開啟 07 →
角色 2 → 進劇集設定
hover 出現「✎ 編輯」
林夜
怪物
+ 新增

怎麼點

  1. 在 07 文本分析確認 頁，往下滾找「抽出的 Elements」
  2. 每組（角色 / 場景 / 道具）右上有「→ 進劇集設定」
  3. 新加：每張 element 卡 hover 會跳出金色「✎ 編輯」chip
  4. 整張卡都是可點連結

→ 直接跳到對應元素的編輯頁（角色 → 15、場景 → 16、道具 → 17）

3

從 13 敘事編輯 — 頂部金色「📚 劇集設定」按鈕（新加 ★）

什麼時候用：寫劇本時隨時想改角色，這是最常走的路
開啟 13 →
劇集設定 →
林夜
怪物
頂部一直在 📚 劇集設定
夜，巷弄 霧氣升起，林夜 持 油燈 步入...

怎麼點（3 個位置）

  1. 頂部 toolbar 金色按鈕 「📚 劇集設定」一直在
  2. 左側 sidebar 頂部金色 banner「劇集設定 →」
  3. 左側「出場角色 / 場景 / 道具」標題旁的 → 各自直跳
  4. 中央敘事文字裡的 @chip（互動需 JS、mockup 是 static）

→ 13 是 R2V 主路徑，這條最常用

4

從 15/16/17 之間互跳

已經在劇集設定內，要切角色 ↔ 場景 ↔ 道具
開啟 15 →
劇集設定
3 tab 切換
角色
場景
道具

怎麼切

  1. 進到任一 element 編輯頁（15 / 16 / 17）
  2. 左 sidebar 頂部有「角色 3 / 場景 3 / 道具 2」三個 tab
  3. 點任一個直接切到那類元素編輯
  4. 選好 element 後右側內容就更新

→ 連續調整 3 類元素時最順

✓ 修了什麼讓你不會再迷路

  • 13 敘事編輯頂部加金色「📚 劇集設定 3 角色 · 3 場景 · 2 道具」按鈕，跟分鏡卡切換並列，不會錯過
  • 07 文本分析每張 element 卡 hover 出現「✎ 編輯」金色 chip + 卡片整張變金色 highlight
  • 07 layout 修了右側生成確認卡用 `align-self: start` + sticky，不再產生大片黑色空白
  • 02 Home sidebar「劇集設定」加 badge 7（顯示元素總數）+ 永久 active 連結
